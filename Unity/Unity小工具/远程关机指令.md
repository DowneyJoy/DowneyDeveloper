
在Unity中实现远程关机，核心思路是让控制端程序通过网络向目标机器发送关机指令。实现方式主要有以下几种，你可以根据目标机器的操作系统和网络环境来选择。

### 方案一：调用 Windows 原生 `shutdown` 命令（最直接）

这是最简单的方式，适用于局域网内的Windows设备。通过 `System.Diagnostics.Process` 在控制端启动一个进程，执行 `shutdown` 命令并指定目标机器。
```c#

using System.Diagnostics;
using UnityEngine;
using Debug = UnityEngine.Debug;

public class RemoteShutdown : MonoBehaviour
{
    public string targetIP = "192.168.1.100"; // 目标机器IP

    public void ShutdownTarget()
    {
        // -m \\IP 指定远程计算机
        // -s 关机
        // -f 强制关闭正在运行的应用程序
        // -t 0 设置超时为0秒
        string arguments = $"-m \\\\{targetIP} -s -f -t 0";

        ProcessStartInfo psi = new ProcessStartInfo
        {
            FileName = "shutdown",
            Arguments = arguments,
            CreateNoWindow = true, // 不显示命令提示符窗口
            UseShellExecute = false
        };

        try
        {
            Process.Start(psi);
            Debug.Log($"关机指令已发送至 {targetIP}");
        }
        catch (System.Exception e)
        {
            Debug.LogError($"发送关机指令失败: {e.Message}");
        }
    }
}
```

**关键点**：`shutdown` 命令要求执行者拥有目标机器的**管理员权限**（或“强制从远程系统关机”的用户权限）。你需要确保控制端运行Unity程序的账户，在目标机器上具有相应的权限。

### 方案二：通过 WMI 进行远程管理（更专业、可控性强）

WMI（Windows Management Instrumentation）是Windows系统管理的核心接口，比调用命令行更灵活，支持跨域、超时控制和更详细的错误反馈，是企业级工具更推荐的方式。

**核心思路**：连接到远程机器的WMI服务（`root\cimv2`命名空间），调用 `Win32_OperatingSystem` 类的 `Win32Shutdown` 方法。参数 `6` 表示强制关机，`2` 表示重启。

**代码框架（需引用 `System.Management`）：**

```c#
using System.Management;
using UnityEngine;

public class WmiRemoteShutdown : MonoBehaviour
{
    public string targetIP = "192.168.1.100";
    public string username = "Administrator";
    public string password = "your_password";

    public void ShutdownViaWmi()
    {
        try
        {
            ConnectionOptions options = new ConnectionOptions
            {
                Username = username,
                Password = password,
                Authentication = AuthenticationLevel.PacketPrivacy,
                Impersonation = ImpersonationLevel.Impersonate
            };

            ManagementScope scope = new ManagementScope($"\\\\{targetIP}\\root\\cimv2", options);
            scope.Connect();

            ObjectQuery query = new ObjectQuery("SELECT * FROM Win32_OperatingSystem");
            ManagementObjectSearcher searcher = new ManagementObjectSearcher(scope, query);

            foreach (ManagementObject mo in searcher.Get())
            {
                // 6 = 强制关机, 2 = 重启
                ManagementBaseObject inParams = mo.GetMethodParameters("Win32Shutdown");
                inParams["Flags"] = 6; 
                mo.InvokeMethod("Win32Shutdown", inParams, null);
            }
            Debug.Log("WMI关机指令已发送");
        }
        catch (System.Exception e)
        {
            Debug.LogError($"WMI关机失败: {e.Message}");
        }
    }
}
```

**前置条件**：目标机器需开启 **Remote Registry** 和 **Server** 服务，并开放防火墙的 **135、445** 及 WMI 动态端口。

### 方案三：通过 SSH 执行命令（跨平台，适合Linux/macOS）

如果目标机器是Linux/macOS，或者你希望在Windows上建立更安全的连接，SSH是最通用和安全的方案。

**核心思路**：在Unity中使用 **[SSH.NET](https://ssh.net/)** 这类库，通过SSH连接到目标机器，执行 `shutdown` 或 `poweroff` 命令。

**关键步骤**：

1. 在Unity项目中导入 [SSH.NET](https://ssh.net/) 库。
2. 使用密钥对进行认证（避免在代码中硬编码密码）。
3. 执行关机命令，例如 `sudo shutdown -h now`。为避免交互式密码提示，需在目标机配置免密码 `sudo` 权限。

### 方案四：自定义客户端-服务器通信（最灵活）

你之前实现的WoL广播，也可以用来扩展成一套自定义的远程关机系统。思路是：

1. **目标机器上运行一个“服务端”程序**：这个程序可以是一个简单的Unity应用，或一个独立的C#/Python脚本，它监听一个特定的UDP或TCP端口。
2. **Unity控制端发送指令**：当需要关机时，控制端向目标机器的IP和端口发送一个特定的消息（例如字符串 `"SHUTDOWN"`）。
3. **服务端接收并执行**：服务端收到指令后，在其本地调用 `shutdown` 命令来关闭计算机。

这种方式最灵活，可以自定义指令格式，但需要在每台目标机器上部署和维护服务端程序。

------

### ⚠️ 重要前提与常见问题

无论选择哪种方案，都需要注意以下几点：

- **权限是核心**：远程关机操作几乎总是需要目标机器的**管理员权限**。你需要确保控制端程序使用的账户在目标机器上拥有相应权限。
- **防火墙设置**：目标机器的防火墙必须允许相应的通信。例如，`shutdown` 命令和WMI需要开放特定端口，自定义服务端则需要开放你监听的端口。
- **网络连通性**：控制端和目标机器必须处于同一局域网，或者网络配置允许它们之间的通信（如VPN）。
- **测试与调试**：建议先在命令行手动测试 `shutdown -m \\IP -s -f -t 0` 命令，确认权限和网络无误后，再集成到Unity代码中。

如果你的目标机器都是Windows且在同一局域网，**方案一（调用`shutdown`命令）** 是最快能跑通的。如果需要更稳定、可编程性更强的方案，可以尝试**方案二（WMI）**。
