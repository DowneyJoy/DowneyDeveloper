### 仅当大文件只在**最后一次提交**中时（最简单的捷径）

如果这个大文件是你**最后一次 `commit` 才加进去的**，历史很简单，可以用 `git reset` 快速回退，而不需要动用 filter-repo 这种重武器。

```
# 回退到上一个提交，并保留工作区的文件（取消提交）
git reset --soft HEAD~1
```

然后，从工作区和暂存区中彻底删除该文件：

```
git rm --cached "Assets/Fonts/123/No.asset"
# 如果你也不想保留本地文件，可以直接 rm "Assets/Fonts/123/No.asset"
```

重新提交，这次不包含大文件：

```
git commit -m "移除超大资源文件 No.asset，避免超过 GitHub 限制"
git push origin signnew
```

### 预防再次发生

清理完毕后，务必在项目根目录的 `.gitignore` 文件中添加规则，防止这个大文件未来被意外再次提交：

```
echo "Assets/Fonts/123/No.asset" >> .gitignore
git add .gitignore
git commit -m "在 .gitignore 中忽略超大资源文件 No.asset"
git push
```
