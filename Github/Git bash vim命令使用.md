# Git Bash 中 Vim 命令指南

在 Git Bash 中，`vim` 是默认文本编辑器。执行 `git commit`（不带 `-m`）、`git rebase -i`、`git config --edit` 等命令时，Git 会自动打开 vim。

---

## 🚨 最重要的：如何保存并退出

vim 打开后默认处于**普通模式**，不能直接打字。先按 `Esc`，再输入冒号命令，最后回车。

| 操作                   | 按键                 | 说明             |
| ---------------------- | -------------------- | ---------------- |
| **保存并退出**         | `Esc` → `:wq` → 回车 | 最常用           |
| **不保存强制退出**     | `Esc` → `:q!` → 回车 | 改错了想放弃时用 |
| **只保存不退出**       | `Esc` → `:w` → 回车  |                  |
| **只退出（未修改时）** | `Esc` → `:q` → 回车  |                  |
| **快捷保存退出**       | `Esc` → `ZZ`         | 等价于 `:wq`     |

> 关键点：先按 `Esc` 确保回到普通模式，再输入 `:` 开头的命令，最后回车执行。

---

## 🧠 理解 vim 的模式

| 模式           | 进入方式                      | 用途                           |
| -------------- | ----------------------------- | ------------------------------ |
| **普通模式**   | 打开时默认；按 `Esc` 随时回到 | 移动光标、删除、复制、执行命令 |
| **插入模式**   | 普通模式下按 `i` / `a` / `o`  | 正常打字输入                   |
| **命令行模式** | 普通模式下按 `:`              | 保存、退出、搜索替换等         |

**核心口诀**：想打字 → 按 `i` 进入插入模式；想执行命令 → 按 `Esc` 回到普通模式再按 `:`。

---

## ✏️ 进入插入模式（开始打字）

在普通模式下：

| 按键 | 作用                     |
| ---- | ------------------------ |
| `i`  | 在光标**前**插入         |
| `a`  | 在光标**后**插入         |
| `o`  | 在**下一行**新开一行插入 |
| `O`  | 在**上一行**新开一行插入 |
| `I`  | 跳到行首并插入           |
| `A`  | 跳到行尾并插入           |

打完字后，按 `Esc` 回到普通模式，再 `:wq` 保存退出。

## 🧭 普通模式下的常用操作

### 移动光标

| 按键                | 作用                    |
| ------------------- | ----------------------- |
| `h` `j` `k` `l`     | 左、下、上、右          |
| `0` / `$`           | 行首 / 行尾             |
| `gg` / `G`          | 文件开头 / 文件结尾     |
| `:n`                | 跳到第 n 行（如 `:10`） |
| `w` / `b`           | 下一个词 / 上一个词     |
| `Ctrl+f` / `Ctrl+b` | 向下 / 向上翻页         |

### 编辑

| 按键          | 作用                                       |
| ------------- | ------------------------------------------ |
| `x`           | 删除光标处字符                             |
| `dd`          | 删除整行                                   |
| `yy`          | 复制整行                                   |
| `p`           | 粘贴到光标后                               |
| `u`           | 撤销                                       |
| `Ctrl+r`      | 重做                                       |
| `/关键词`     | 向下搜索，回车跳转，`n` 下一个，`N` 上一个 |
| `:%s/旧/新/g` | 全文替换                                   |

## 🛠️ Git 场景中的 vim 实战

### 场景 1：`git commit` 打开 vim 写提交信息

```bash
git commit
```

vim 打开后：

1. 按 `i` 进入插入模式
2. 输入提交信息，例如 `修复 TCP 断线重连空引用异常`
3. 按 `Esc`
4. 输入 `:wq` 回车

### 场景 2：`git rebase -i` 编辑 todo 列表

```bash
git rebase -i HEAD~3
```

vim 打开后你会看到类似：

```text
pick abc1234 第一次提交
pick def5678 第二次提交
pick ghi9012 第三次提交
```

- 按 `i` 进入插入模式
- 把想合并的行的 `pick` 改成 `squash`（合并到上一个提交）
- 或改成 `reword`（改提交信息）、`drop`（丢弃）
- 按 `Esc` → `:wq` 回车

### 场景 3：编辑 `.gitignore` 或 `.bashrc`

```bash
vim .gitignore
```

按 `i` 输入内容，`Esc` 后 `:wq` 保存。

## 🔄 不想用 vim？换成其他编辑器

```bash
# 换成 nano（简单，底部有快捷键提示）
git config --global core.editor "nano"

# 换成 VS Code（需已安装 code 命令）
git config --global core.editor "code --wait"

# 换成 Notepad++
git config --global core.editor "'C:/Program Files/Notepad++/notepad++.exe' -multiInst -nosession"
```

nano 的保存退出是 `Ctrl+O` 回车保存、`Ctrl+X` 退出，对新手更友好。

## 💎 一句话总结

**vim 打开后不能直接打字，先按 `i` 进入插入模式；改完后按 `Esc` 回到普通模式，再输入 `:wq` 回车保存退出。** 如果只是误入想放弃，`Esc` 后 `:q!` 回车即可。实在不习惯，用 `git config --global core.editor "nano"` 换成更简单的编辑器。
